## 你的高概率短板与应答策略

| 可能被追问的短板 | 建议回答结构 | 优先复习 |
|---|---|---|
| 主力是 C#，岗位偏 Python/Java/Go | 先讲分布式/接口/可观测等可迁移能力，再给 Python FastAPI 可运行证据；不宣称“精通”未长期使用的语言 | ENG-01/02/10、AGENT-03 |
| Dify/Coze 实战较少 | 能讲工作流、变量、知识库、插件、错误分支和私有化；明确复杂 Runtime 何时回到代码 | MCP-09、MCP-08 |
| 微调和模型服务不是核心经历 | 先判断知识/行为/实时动作，再说明 RAG、SFT/LoRA、工具的边界；准备一个最小训练与 vLLM 部署方案 | LLM-08、ENG-05/06 |
| 多租户/权限案例不够突出 | 从 tenant ID 可信注入、召回前 ACL、缓存/日志隔离、工具最小权限、越权测试回答 | RAG-11、ENG-03、EVAL-11 |
| GraphRAG/知识图谱深度可能被问 | 先给适用条件和 vector baseline，再讲实体关系、多跳 gold、增量与权限成本 | RAG-12、PROJ-02 |
| 专家岗会追问规模与 Owner 深度 | 只给可证实的 27,646 / 75 / 461 等数字；区分公开 Demo 与历史内部背景，主动说当前边界和下一步 | PROJ-01、PROJ-04、PROJ-11～15 |
| 垂直行业经验不足（政务/金融/医疗/游戏） | 不伪装业务经验；用权限、引用、时效、合规、审计和人审框架迁移，再提出需向业务方核验的问题 | EVAL-10/11、ENG-03/04/08 |

## 面试前 30 分钟选题法

1. 从 JD 圈出 5 个动词：**设计、开发、部署、评测、优化**。
2. 每个动词选 1 道基础题 + 1 道项目题；例如“优化检索”对应 RAG-05 + PROJ-09。
3. 准备一个“不用某技术”的判断题，体现取舍：AGENT-13、RAG-12、MCP-09 或 ENG-06。
4. 最后复述 PROJ-01 和岗位最相关的 3 个项目追问，确保数字与边界一致。
