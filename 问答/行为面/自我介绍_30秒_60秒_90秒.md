## 60 秒版

面试官您好，我叫刘启仁，本硕毕业于电子科技大学，在微软广告做了四年软件工程师。我的工作主要有两条主线。

第一条是 AI Agent。我设计并实现了 Commit AI Resolver，用于多仓库历史变更检索和回归调查。它结合精确标识符、关键词和向量检索；Incident Commander 再根据当前证据动态调用 Retrieval、Diff Investigator 和 Evidence Critic。外围 Harness 负责证据授权、工具权限、多维预算、校验和回退，让结果可追溯、可诊断。

第二条是大型广告系统的端到端交付。我参与过 React 前端和 C# 后端项目，负责性能优化、图片资产治理、Deal 自动同步和视频推荐等链路，其中关键页面的生产 P95 降低了 40% 到 72%。我的优势是能把 AI 能力与成熟的软件工程方法结合起来。下一步我希望继续从事 AI 应用和 Agent 工程，把原型推进为可靠、可持续迭代的产品。

## 90 秒版

面试官您好，我叫刘启仁，本硕毕业于电子科技大学，之后在 Microsoft Advertising 做了四年软件工程师。我的经历主要包括 AI Agent 和大型广告系统两部分。

在 AI Agent 方向，我设计并实现了 Commit AI Resolver，解决多仓库历史变更检索和回归调查问题。它对 27,646 条公开 React Commit 做精确、关键词、向量和结构化混合召回；Incident Commander 根据工具结果动态委派 Retrieval、Diff Investigator 和 Evidence Critic。SDK 外的 Harness 强制执行 Candidate Ledger、工具权限、预算、超时、校验和回退。我已经用真实 DeepSeek、Qwen3 Embedding 和 GitHub Diff 跑通一条 gold RCA：系统命中目标修复 Commit，Critic 也因为 introducing commit 证据缺失主动降级。检索侧的 Issue 时间窗和本地 LTR 在 grouped 134-case held-out test 上把 Recall@20 从 70.90% 提高到 94.78%；Gate v2 仍待负例标定后接入。这让我认识到，Agent 的难点不仅是模型规划，更是让检索、门禁、评测和证据链一起演进。

在大型广告系统方面，我长期参与 React 前端和 C# 后端的端到端交付。前端做过素材、第三方监测、Deal、推荐和性能专项，关键页面生产 P95 降低了 40% 到 72%；后端做过图片资产生命周期治理、Deal 自动同步和异步视频推荐链路，也积累了从方案设计、跨团队协作到灰度上线和生产运维的完整经验。

我的优势是既有大型系统的交付基础，也能从评测和可靠性的角度做 Agent。下一步我希望继续深耕 AI 应用工程，把 Agent 从原型推进为可上线、可观测、可持续优化的产品。

## 使用提示

- 默认优先使用 **60 秒版**：信息完整，同时能给面试官留下追问项目的空间。
- 面试官明确要求“简单介绍”时使用 **30 秒版**。
- 业务面、主管面或明确给出 1–2 分钟时使用 **90 秒版**。
- 不要刻意加快语速；如果被中途打断，直接顺着面试官的问题展开即可。
