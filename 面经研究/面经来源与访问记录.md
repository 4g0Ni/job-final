## 3. 本次面经提炼出的高频主题

### AI / Agent

- 项目完整链路与为什么采用 Agent/多 Agent，而不是 workflow 或单 Agent。
- RAG 分块、混合检索、Rerank、评测与 badcase 回流。
- Memory/Context 压缩、重复状态、工具失败恢复与循环终止。
- MCP/Skill/Harness/Tool Calling 的层次区别。
- 多租户、权限、沙箱、恶意用户、Prompt Injection 与审计。
- AI Coding 的真实提效、边界和大代码库上下文治理。

### UI / 前端

- React 重渲染、SSE 高频更新、长文本渲染与性能测量。
- 浏览器事件循环、Promise、缓存、网络与前端系统设计。
- AI 工作流可视化编辑器、流式聊天 UI、跨渠道 Agent 展示。
- 项目深挖、工程化、测试、可访问性与跨端协作。

### MT / 后端

- 并发、异步、队列、缓存、数据库索引与一致性。
- 限流、幂等、重试、熔断、分布式任务和系统容量。
- Agent 服务中的 streaming、RAG、MCP、多租户和权限设计。
- 项目指标、线上故障、系统瓶颈与技术选型。

### Metrics / 数据

- analysis unit、口径统一、幂等回填和数据质量。
- A/B 实验显著性、样本量、置信区间、多重检验与 SRM。
- Spark/SCOPE 的 shuffle、数据倾斜、分区和作业优化。
- AI/Agent 的成功率、工具准确率、成本、延迟和人工评审一致性。
